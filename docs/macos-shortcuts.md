# MacOS Shortcuts

> #macos #terminal #shortcuts #productivity

## General 

Lock screen
```
[CTRL] + [CMD] + Q
```

Quit focused application
```
[CMD] + Q
```

Hide front app
```
[CMD] + H
```

Hide all windows of front app
```
[OPTION] + [CMD] + H
```

Close front app
```
[CMD] + W
```

Close all windows of front app
```
[OPTION] + [CMD] + W
```

Find
```
[CMD] + F
```

Find again (next occurrence)
```
[OPTION] + [CMD] + G
```

Find again (previous)
```
[SHIFT] + [OPTION] + [CMD] + G
```


## Terminal shortcuts

### Edit CLI

Reposition insertion point 
```
[OPTION] + click
```

Move insertion point to start of line
```
[CTRL] + A
```

Move insertion point to end of line
```
[CTRL] + E
```

Move insertion point forward one word
```
[OPTION] + right-arrow
```

Move insertion point back one word
```
[OPTION] + left-arrow
```

Delete entire line
```
[CTRL] + U
```

Delete until end of line
```
[CTRL] + K
```

Delete forward to end of word (available when “use option as meta-key” is selected)
```
[OPTION] + D
```

Delete backward to beginning of word
```
[CTRL] + W
```

Delete forward one character
```
[FN] + [DELETE]
```

Select complete file path
```
[CMD] + [SHIFT] + double-click
```

Rectangular select box
```
[OPTION] (hold) + click (drag cursor)
```

Select URL
```
[SHIFT] + [CMD] + double-click
```

Open URL
```
[CMD] + dounle-click 
```


## Notes application shortcuts

Monostyle format
```
[SHIFT] + [CMD] + M
```

Blockquote format
```
[CMD] + ' 
```

Show [and hide] folders
```
[OPTION] + [CMD] + S
```

Show notes list view
```
[CMD] + 1
```

Show notes gallery view
```
[CMD] + 2
```

Show attachments
```
[CMD] + 3
```

Search ALL notes
```
[OPTION] + [CMD] + 1
```

Change font (for Apple’s annoying monospaced classification)
```
[CMD] + T
```
